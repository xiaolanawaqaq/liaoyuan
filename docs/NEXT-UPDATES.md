# 下一轮更新建议 — 截图核对

这份记录是对用户提供截图的评估，不表示这些功能已开发完成。

## 当前代码核对

1. **触屏「查看 / 施工」切换：尚未实现。** `scripts/board.gd` 的格子输入仍以鼠标按钮/移动事件驱动，触屏模拟点击会直接发出施工信号；`scripts/main.gd` 的格子详情依赖悬停。手机用户缺少可靠的不消耗行动点的查看入口。
2. **无尽模式：尚未实现。** `scripts/sim.gd` 只有五关固定关卡，状态验证、风向计划和存档均绑定现有关卡数据。增加程序化波次不只是多放一个按钮，需验证每波可解、重生火源公平、计分和存档隔离。
3. **一键复制战绩：尚未实现。** 当前结算只展示回合、植被保留和星级，没有复制文本入口。
4. **成就、英文、联网、AAB：本次未增加。** APK 发布不要求为这轮维护加入以上内容。

## 建议顺序

先做触屏查看与施工切换，再做结算分享；这两项直接改善手机可用性和传播。之后用单独的挑战入口增加可重复游玩的模式，而不是仓促把五关结算改成无限重刷。

「要有人玩」不能只用功能数量或测试通过证明。手机布局、点击命中区域、新手是否理解预判、首次通关时间，都需要安卓实际安装与玩家试玩反馈。

## 另一个发现

自动快进目前要求无燃烧格才启用，但模拟层在火烧尽时已立即判胜，因此这个触发条件在正常游玩状态下不能到达。以后改善回合节奏应先调整这一逻辑并添加对应测试，不能继续把它描述成已验证生效的体验优化。

本轮仅更换签名密钥并重新导出 APK，不混入未获确认的新玩法。手机查看、分享、挑战模式都保留为建议，不冒充已经完成。
